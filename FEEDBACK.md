# Зигзаг — фич-реквесты и баг-репорты

Формат записи: `FR-N` — фич-реквест, `BUG-N` — баг. У каждой записи: статус
(`новое` / `сделать` / `в работе` / `готово`), суть, критерий готовности.
Статусы синхронизируются с доской Buildin Feedback: новое ↔ Без категории,
сделать ↔ Сделать, в работе ↔ В работе, готово ↔ Завершено.
## Фич-реквесты

### FR-1: Enter подтверждает кнопку «Дальше» (готово)
В модалке победы между уровнями клавиша Enter активирует кнопку «Дальше» (фокус по умолчанию на ней). Готово: Enter на открытом окне результата переходит на следующий уровень.

### FR-2: (нужно найти музыку) Фоновая релаксирующая музыка (новое)
Ненавязчивое фоновое звуковое сопровождение (спокойное, расслабляющее),
стартует после первого взаимодействия, глушится на паузе/рекламе/скрытой
вкладке. Готово: музыка играет во время игры, не мешает, отключаема.

### FR-3: Виброотклик на флажок + трёхпозиционный переключатель (новое)
При попадании на клетку с цифрой — короткий виброотклик
(`navigator.vibrate`, только где поддерживается). В шапке одна иконка
с тремя состояниями по кругу: звук вкл → только вибро → всё выкл.
Выбор хранится в прогрессе. Готово: вибро на флажке работает,
переключатель циклит 3 состояния, состояние переживает перезагрузку.

### FR-4: тихий режим интерфейса после обучения (новое)
Блок «Как играть» после 1–2 пройденных уровней сворачивается сам и не мозолит
глаз; страница держит фокус на поле (референс чистоты: play2048.co).
Готово: новичок видит гайд, опытный — только поле, букв минимум.

### FR-5: обучающий нулевой уровень «за руку» (новое)
Уровень 0, где игра ведёт пальцем: подсвечивает старт, тянет линию-призрак,
игрок просто повторяет и усваивает механику без чтения правил.
Готово: игрок, не читавший правила, проходит 0-й уровень и понимает цель.

### FR-6: явная прогрессия сложности и механик (новое)
Сейчас растёт только поле, на 40-х (6×6) легче, чем на 5×5. Нужны: калиброванная
рампа по метрикам решателя, ввод новых механик порциями (стенки → …),
чекпоинт-паки. Готово: медианное время прохождения растёт от пака к паку,
новых механик минимум 2 сверх стенок.
## Баг-репорты

### BUG-1: подсказка сдаётся на неверном пути вместо отката (готово)
Уровень 3 (4×4): игрок увёл линию не туда (2/16), нажал «Подсказка» —
получил «Не вижу продолжения отсюда» без помощи. Причина: в билде нет
эталонного решения, решатель честно не находит продолжения с ошибочного
хвоста и просто разводит руками (в прототипе подсказка откатывала линию
назад по эталону). Ожидаемо: подсказка сама шагает назад по пути до первой
точки, откуда продолжение есть, ставит линию туда и подсвечивает следующий
шаг. Готово: на любом неверном хвосте подсказка откатывает и показывает ход,
тупикового тоста больше нет.
